Process
- Check a square 
- If at end, return list with cords tuple
- For each move you can make:
    - Make sure you can still move there
    - If yes, move to that square
        - If that move returns a list, concat cords and return list
        - If None, move to the next possible move
    - If no, continue
- If no more moves, return None
